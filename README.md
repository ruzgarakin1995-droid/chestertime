# 🛋️ CHESTER TIME — Özel Chester & Tasarım Koltuk Web Sitesi

İmalatçıdan doğrudan satış yapan **Chester Time** işletmesi için hazırlanmış, Awwwards kalitesinde modern Next.js web uygulaması.

---

## 🚀 Kurulum ve Çalıştırma

```bash
# 1. Bağımlılıkları yükleyin:
npm install

# 2. Geliştirici sunucusunu başlatın:
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresine gidin.
